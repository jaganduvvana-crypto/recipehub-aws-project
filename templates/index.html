BUILT FOR THE CLOUD

Simple For You.
Powerful Behind The Scenes.

RecipeHub demonstrates how AWS cloud services work together to provide authentication, database storage, and private image storage for a web application.

01 / AUTHENTICATION

Amazon Cognito

Handles user signup and login, allowing the application to associate published recipes and reviews with members.

02 / DATABASE

Amazon RDS MySQL

Stores recipe titles, descriptions, image object keys, member information, ratings, and comments in relational tables.

03 / IMAGE STORAGE

Amazon S3

Stores uploaded recipe photographs privately. Presigned URLs allow temporary image access without making the bucket public.
